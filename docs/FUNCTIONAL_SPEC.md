## 1. 개요

### 1.1 서비스 한 줄 소개
관심 기업을 검색하면 재무제표·시세·뉴스·사업보고서를 바탕으로 **AI가 쉬운 말로 풀어 쓴 기업 분석 리포트**를 보여주는 주식 초보자(10대 포함)용 서비스.

### 1.2 핵심 원칙
1. **어려운 재무 정보를 쉬운 말로**: 전문용어는 없애지 않고, 누르면 바로 쉬운 설명을 보여준다.
2. **숫자는 공식 자료 그대로, AI는 설명만**: 재무 숫자는 DART·한국거래소 원본 값을 쓰고, AI가 숫자를 새로 만들지 않는다.
3. **투자 추천이 아니라 이해를 돕는다**: 매수·매도를 권유하는 표현을 쓰지 않는다.
4. **숫자보다 문장**: "영업이익 +33%" 대신 "작년보다 33% 더 벌었어요". 말투는 친근한 "~해요" 체.

### 1.3 범위

| 구분 | 내용 |
|---|---|
| MVP 포함 | 기업 검색, 시세·재무 그래프, AI 리포트 생성·조회, 재무 분석, 뉴스, 기업 정보, 퀴즈, 용어 설명, 용어 카드, 관심 기업, 로그인 |
| MVP 제외 (향후 확장) | 모의투자, 커뮤니티, 알림, Face ID 로그인, 게스트 이용 |

## 2. 사용자와 용어

| 용어 | 의미 |
|---|---|
| 사용자 | 주식 초보 투자자. 전문용어에 익숙하지 않다고 가정 |
| 확인된 값 | DART·한국거래소·회사 공식 실적 발표로 확인한 숫자 |
| 예시 값 | 아직 확인하지 않아 임시로 넣은 숫자. 데이터에 `is_sample: true`, 화면에 "예시 값" 배지 |
| 저장된 리포트 | 이미 생성해 서버에 보관 중인 AI 리포트. 다시 열면 생성 과정 없이 바로 보여줌 |
| 전문용어 | 매출액, 영업이익, 영업이익률, 순이익, 부채비율, ROE, PER, PBR, 시가총액, 현금흐름, 사업보고서, 공시, HBM, 파운드리 (용어 사전으로 관리) |

## 5. 기능 상세

### F-01 기업 검색

| 항목 | 내용 |
|---|---|
| 설명 | 회사 이름(한글·영어)이나 종목코드로 회사를 찾는다 |
| 입력 | 검색어 (공백 무시, 영어는 대소문자 무시) |
| 처리 | 한글 이름·영어 이름·종목코드 중 하나라도 검색어를 포함하면 결과에 포함. 입력 후 150ms 동안 추가 입력이 없으면 검색 |
| 출력 | 목록 항목: 이니셜 아이콘, 회사명, 영문명·종목코드·업종, 현재가, 등락률(상승 빨강 / 하락 파랑) |
| 검색 전 화면 | 가운데 큰 검색창 + 예시 검색어(삼성 / samsung / 005930). 아래에 "많이 보는 회사" 목록(순위 표시)과, 오른쪽에 "오늘의 용어" 카드(날짜마다 바뀜)·"다진은 이렇게 써요" 3단계 안내 |
| 상단 검색창 | 홈이 아닌 화면에서도 상단 내비게이션의 검색창으로 회사를 찾는다. 입력하면 최대 6개 결과가 펼쳐지고, Enter는 첫 번째 결과 선택, Esc는 닫기 |
| 예외 | 결과 없음 → "찾는 회사가 없어요" / 리포트가 준비되지 않은 회사 선택 → 이동하지 않고 안내 토스트 (시연: "시연에서는 삼성전자 리포트만 준비되어 있어요") |
| API | `GET /api/companies?query=`, `GET /api/companies/popular` |

**수용 기준**
- [ ] "삼성", "samsung", "005930" 각각 검색 시 삼성전자가 나온다
- [ ] "samsung" 검색 결과에 SK하이닉스는 나오지 않는다
- [ ] 리포트가 없는 회사를 누르면 안내가 뜨고 화면은 그대로다

### F-02 기업 시세 요약 (기업 상세 상단)

| 항목 | 내용 |
|---|---|
| 설명 | 기업 상세 화면 위쪽에 회사의 기본 시세를 보여준다 |
| 출력 | "뒤로" 버튼, 회사 아이콘·회사명·영문명·종목코드·시장, 현재가(크게), "어제보다" 등락률, 업종 태그, 시가총액 태그, 관심 기업 하트. 그 아래 탭 바는 스크롤해도 상단 내비게이션 아래에 고정 |
| 사이드바 | 넓은 화면에서 오른쪽에 고정: ① AI 리포트 카드(상태 문구 + 리포트 버튼, F-04) ② 주요 지표(시가총액, PER, PBR, ROE, 부채비율) ③ 교육용 안내. 좁은 화면에서는 본문 아래로 이동하고, 리포트 버튼은 회사 정보 아래에 표시 |
| 규칙 | 예시 값인 항목 옆에는 "예시 값" 배지 |
| 예외 | 존재하지 않거나 준비되지 않은 회사 → 오류 문구와 "홈으로 가기" 버튼 |
| 데이터 출처 | 현재가·등락률·시가총액: 한국거래소 (pykrx / FinanceDataReader) |
| API | `GET /api/companies/{stock_code}` |

### F-03 차트 탭 (AI 분석 전 기본 화면)

| 항목 | 내용 |
|---|---|
| 설명 | 기업 상세를 처음 열면 AI 분석 전에 일반 주식 앱처럼 시세·재무 그래프를 먼저 보여준다 |
| 주가 흐름 | 기간 선택(1달 / 3달 / 6달 / 1년, 기본 3달), 기간 등락률, 기간 중 최고·최저가, 그래프를 누르면 날짜·종가 표시. 기간 동안 올랐으면 빨강, 내렸으면 파랑 |
| 재무제표 한눈에 | 매출 / 영업이익 3년 막대그래프(토글 전환, 최신 연도 진하게), "작년보다 N% 더 벌었어요" 문장, 단위·기준·출처, "재무 분석 자세히 보기" 버튼 |
| 주요 지표 | 사이드바에 표시 (F-02) |
| 리포트 버튼 | 사이드바의 "AI 리포트 작성" 버튼 (F-04) |
| 데이터 출처 | 주가: 한국거래소 / 재무: OpenDART |
| API | `GET /api/companies/{stock_code}/prices?period=1m\|3m\|6m\|1y`, `GET /api/companies/{stock_code}/financials` |
| 현재 상태 | 주가 흐름은 예시 데이터(`is_sample: true`). 재무 숫자는 확인된 값 |

### F-04 AI 리포트 생성·저장·재작성

| 항목 | 내용 |
|---|---|
| 설명 | 사용자가 버튼을 눌렀을 때만 AI 리포트를 만든다. 한 번 만든 리포트는 저장해 두고 다음에는 바로 보여준다 |
| 트리거 | 사이드바(좁은 화면에서는 회사 정보 아래)의 "AI 리포트 작성" 버튼, 또는 AI 리포트 탭의 "AI 리포트 작성" 버튼 |
| 처리 흐름 | ① 기업 화면을 열면 저장된 리포트가 있는지만 확인 → ② 없으면 버튼 "AI 리포트 작성" → ③ 누르면 AI 리포트 탭으로 이동하고 생성 요청 → ④ 생성 단계 표시 → ⑤ 완료되면 요약이 타이핑되듯 나타나고 나머지 섹션 표시 |
| 생성 단계 표시 | "DART 재무제표 불러오기 → 최근 뉴스 확인하기 → 사업보고서 비전 읽기 → AI가 쉬운 말로 정리하기" 순서로 체크 |
| 완료 표시 | 새로 만든 경우 "O초 만에 생성" / 저장된 리포트인 경우 "저장된 리포트 · 바로 불러왔어요" |
| 버튼 상태 | 확인 중: 비활성 / 없음: "AI 리포트 작성" / 생성 중: "AI가 리포트를 쓰고 있어요…" / 있음: "AI 리포트 보기" 또는 "저장된 AI 리포트 보기" / AI 리포트 탭을 보는 중: "다시 작성하기" |
| 재작성 | 요약 카드의 "다시 작성하기" → 새로 생성해서 덮어쓴다 |
| 예외 | 생성 실패 → "리포트를 만들지 못했어요" 문구와 "다시 작성하기" 버튼 |
| API | `GET /api/companies/{stock_code}/report` (저장된 리포트, 없으면 404) / `POST /api/companies/{stock_code}/report` (생성) |
| AI 입력 데이터 | DART 재무제표, 최근 뉴스, 사업보고서(비전) |

**수용 기준**
- [ ] 기업 화면을 열기만 해서는 리포트가 생성되지 않는다
- [ ] "AI 리포트 작성"을 누르면 AI 리포트 탭으로 이동하고 생성 단계가 보인다
- [ ] 생성한 뒤 화면을 나갔다가 다시 열면 버튼이 "저장된 AI 리포트 보기"가 되고, 누르면 바로 보인다

### F-05 AI 리포트 구성 ⚠️ 형식 확정 전

> 아래는 **현재 시연용 초안**이다. 뉴스 등을 참고하는 방향은 유지하되, 섹션 구성과 문장 형식은 팀 논의 후 확정한다.
> 섹션은 컴포넌트 단위로 나뉘어 있어서 순서 변경·추가·삭제가 쉽다 (`frontend/src/features/report/reportSections.ts`).

| 순서 | 섹션 | 내용 (현재 초안) | 응답 필드 |
|---|---|---|---|
| 1 | AI 한 줄 요약 | 브랜드 색 큰 카드, 1~2문장. 카드 아래 "재무제표 · 뉴스 · 사업보고서를 함께 분석했어요" | `summary` |
| 2 | 핵심 포인트 3가지 | 실적 / 비전 / 최근 소식 카드. 각각 상태 배지(좋음·보통·주의), 출처·기준일 | `key_points[]` |
| 3 | 그래프로 보면 | 3년 매출, 연도별 영업이익률, 사업별 매출 그래프 + 그래프마다 "AI 설명" | `charts[]` |
| 4 | 세 가지를 이어서 보면 | 비전 → 뉴스 → 재무 숫자의 연결 + 결론 한 문장 | `connection` |
| 5 | 좋은 점 / 지켜볼 점 | 각 2개 | `strengths[]`, `watch_points[]` |
| 6 | 자세히 보기 | 재무제표 / 뉴스 / 사업 내용 탭으로 이동하는 버튼 3개 | (프론트 고정) |
| 7 | 퀴즈 | F-09 | `quiz[]` |
| 8 | 안내 문구 | F-15 | `disclaimers[]`, `data_sources[]` |

**웹 배치**: 핵심 포인트는 넓은 화면에서 3칸, 그래프와 좋은 점/지켜볼 점은 2칸, 자세히 보기 버튼은 3칸으로 나란히 놓는다. 좁아지면 자동으로 칸 수가 줄어든다.

**리포트 그래프 규칙**
- AI(백엔드)는 어떤 그래프를 넣을지(`type`), 제목(`title`), 설명(`caption`)만 정한다.
- 그래프의 숫자는 항상 재무 데이터(F-06과 같은 원본)로 그린다.
- 지원 `type`: `annual_revenue`, `annual_operating_income`, `operating_margin`, `segment_revenue`. 프론트가 모르는 `type`은 건너뛴다.

**문장 작성 규칙 (AI 프롬프트에 반영)**
- 중학생도 이해할 수준, "~해요" 체
- 확인된 수치 외의 숫자를 새로 만들지 않는다 (확인된 값끼리 계산한 비율은 허용. 예: "100원어치 팔면 약 13원을 남겼어요")
- 매수·매도 권유 표현 금지
- 전문용어는 그대로 쓰고 풀어쓰기는 용어 시트(F-10)에 맡긴다

**확정 시 결정할 것**: §9 미결 사항 1번 참고

### F-06 재무 분석

| 항목 | 내용 |
|---|---|
| 3년 실적 그래프 | 매출 / 영업이익 막대그래프(토글), 최신 연도 진하게, 한 문장 설명, 단위·기준(연결)·출처, 최근 분기 실적 카드 |
| 무엇으로 돈을 버나요? | 사업별 매출 가로 막대. **비율이 아니라 금액(조 원)**, 기준 기간 표시 (예: 2025년 4분기 기준) |
| 지표 신호등 | 5개 지표마다 값, 상태 배지, 쉬운 설명 한 줄, 판단 기준 한 줄 (아래 표) |
| 원본 숫자 표 | "재무제표 원본 숫자 보기"를 누르면 펼쳐지는 표 (연도별 매출액·영업이익 + 최근 분기) |
| 웹 배치 | 3년 실적 그래프와 사업별 매출을 나란히 2칸, 지표 신호등은 카드 그리드(폭에 따라 1~3칸) |
| 데이터 출처 | OpenDART (재무제표), 회사 실적 발표 |
| API | `GET /api/companies/{stock_code}/financials` |

**지표 신호등 계산과 판단 기준**

| 지표 | 값 | 좋음 | 보통 | 주의 | 쉬운 설명 예 |
|---|---|---|---|---|---|
| 매출 증가율 | **코드에서 계산**: (올해 매출 − 작년 매출) ÷ 작년 매출 × 100 | 10% 이상 | 0~10% | 감소 | 작년보다 매출이 10.9% 늘었어요 |
| 영업이익률 | **코드에서 계산**: 영업이익 ÷ 매출 × 100 | 10% 이상 | 5~10% | 5% 미만 | 100원어치 팔면 약 13원을 남겼어요 |
| ROE | 데이터 값 | 10% 이상 | 5~10% | 5% 미만 | 주주가 맡긴 돈 100원으로 1년에 약 9원을 벌었어요 |
| 부채비율 | 데이터 값 | 100% 이하 | 100~200% | 200% 초과 | 회사 자기 돈 100원당 빚이 약 27원 있어요 |
| PER | 데이터 값 | 15배 이하 | 15~30배 | 30배 초과 | 지금 주가는 1년 이익의 약 18배예요 (업종마다 다르다고 함께 안내) |

**수용 기준**
- [ ] 매출 증가율·영업이익률은 하드코딩하지 않고 원본 숫자에서 계산된다
- [ ] 예시 값 지표에만 "예시 값" 배지가 붙는다

| 접근성 | 버튼·탭·대화상자에 역할과 이름 지정, 키보드로 모든 기능 사용(탭 이동, Esc로 닫기), 그래프에 텍스트 설명, 움직임 줄이기 설정 시 그래프·화면 애니메이션 끔 |
| 성능 | 저장된 리포트는 생성 없이 바로 표시. 목 서버는 실제 API 모드에서 불러오지 않음 |
| 개인정보 | 이메일·이름만 수집, 민감 정보 미수집. `.env`는 커밋하지 않음 |
| 확장성 | 데이터 흐름 `api/ → hooks/ → 컴포넌트`. `VITE_USE_MOCK=false`로 실제 API 전환 시 화면 코드 수정 없음 |
| 테스트 | 프론트: Vitest + RTL로 핵심만 (용어 시트, 지표 신호등, 검색, 리포트 작성 흐름: 현재 12개) / 백엔드: pytest로 핵심 API·리포트 생성 로직 |
| CI | GitHub Actions에서 lint + test |
